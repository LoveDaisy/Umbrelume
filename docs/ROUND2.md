# 第二轮：定位缺口并加入自由对流层气溶胶消光

## 结论与本轮范围

在已测试的候选中，**较低光路上缺少的额外消光，是当前内部偏亮的主要可改进因素**。
本轮只把气溶胶消光加入生产模型。未同时加入太阳临边昏暗、真实温度廓线、云或散射入射光。
这个选择不是对 2011 年真实大气的唯一因果识别。

默认采用独立文献中的 OPAC 自由对流层先验，固定 AOD550=0.013。
它带来实质改善，但仍不足以完整解释观测。另将 677 nm 单独用于一次 AOD 校准，
并把未参与校准的 503 nm 留作检查；校准值不会成为默认参数。

## 怎样区分候选原因

首轮数值检查和本轮白盒复核没有找到能解释 4–7 倍偏差的归一化、双侧光路或单位错误。
利用生产接收端的同一个环带积分器，可以直接累计各最低高度的光谱贡献。

| 波段、距影心位置 | 贡献累计 P10 / P50 / P90 的最低高度 |
|---|---|
| 677 nm，0.150° | 0.88 / 3.12 / 5.75 km |
| 677 nm，0.400° | 4.62 / 8.07 / 11.10 km |
| 677 nm，0.575° | 7.46 / 11.61 / 15.43 km |
| 503 nm，0.400° | 7.01 / 10.01 / 11.67 km |
| 503 nm，0.575° | 9.90 / 13.63 / 16.20 km |

偏差最大的深红采样点由低层光路主导，较外侧由更高光路主导，提供了可判别的高度结构。
这些分位数属于现有模型的贡献诊断，不是独立测得的光路高度。

对主要替代方向做了两个探针，未将它们加入默认模型：

- **太阳临边昏暗**：取 [Hestroffer & Magnan（1998）Table 2](https://www.physics.hmc.edu/faculty/esin/a101/labs/limbdark.pdf)
  的 Neckel–Labs 经验系数，固定总太阳通量，以归一化的均匀圆盘正权重混合计算。
  677 nm、0.150° 的模型／观测比从 7.10 变为 7.23；503 nm、0.400° 从 4.07 变为 3.78。
  它没有消除主要深红偏差。经验拟合主要适用于太阳半径 0–0.9，极端临边为外推，结论限于此探针。
  混合核与直接角积分独立核对；64→128 阶混合积分的变化约 1.7e-5。
- **密度敏感性**：统一密度比例设为 0.9605 时，最深红光比仍约 6.69。
  这是粗略敏感性，不是热带温度廓线，不能据此排除真实廓线的所有作用。

上一轮的臭氧 300→250 DU 与网格加密探针也远不足以解释数倍偏差。
这些证据共同支持优先实现额外低层消光。气溶胶的种类、实际高度分布与云的区分仍未唯一确定。

## 选择哪一种气溶胶表示

采用 [OPAC 原文 Tables 3、5](https://lweb.cfa.harvard.edu/HITRAN/HITRAN2012/Aerosols/papers/hess_opac_1998.pdf)
的自由对流层组件：2–12 km、指数尺度高度 8 km、AOD550=0.013。
光谱采用连续的分段幂律，在 500–800 nm 用指数 1.58，在 350–500 nm 用 1.21。
这些固定参数来自独立背景模型，不是本次月食的实测廓线；公式与来源统一见
[physics/AEROSOL.md](physics/AEROSOL.md)。

气溶胶光深沿原有的弯曲光路积分，包含完整两侧路径，只改变消光，不改变分子密度与折射率。
积分在气溶胶边界及气体层界分段；路径表加密截断边界附近的最低高度，避免插值跨过尖锐结构。
550 nm 归一化固定在物理波长，而非查询网格。零 AOD 精确恢复原表；同表关闭气溶胶用于严格反事实对照。

这轮没有照搬天空项目的近地边界层预设。尺度高度 1.5 km、AOD550=0.05 的指数廓线，
在 11 km 的消光仅约 2.2e-5 km⁻¹，不能代表此次约束所需的自由对流层组件。

## 效果与仍然存在的残差

下表是模型／观测曲线读数，1 表示相等。采用固定的 2011 年事件距离。

| 波段、角距离 | 首版分子模型 | 固定文献先验 | 仅用 677 nm 校准 AOD |
|---|---:|---:|---:|
| 677 nm，0.150° | 7.10 | 3.76 | 1.07 |
| 677 nm，0.400° | 2.30 | 1.68 | 0.96 |
| 677 nm，0.575° | 1.09 | 0.97 | 0.81 |
| 503 nm，0.400° | 4.07 | 2.99 | 1.75 |
| 503 nm，0.500° | 1.56 | 1.36 | 1.11 |
| 503 nm，0.575° | 1.15 | 1.08 | 0.99 |

固定先验将十八个曲线读数的描述性 RMS(ln(Model/Obs)) 从 1.020 降到 0.700。
这是有意义的部分改善；最深红光仍偏亮约 3.76 倍，不能称为已经匹配真实大气。

额外的**单参数校准**只使用 677 nm 的十个曲线读数，最小化未加权的平方对数比，
将 AOD550 限制在 [0, 0.1]，得到约 0.039706；廓线边界、尺度高度、光谱指数均保持固定。
503 nm 的八个读数没有进入目标函数，其描述性 RMS 从 0.771 降到 0.290。
这支持该物理方向具有跨波段解释力，但仍是同事件检查，不能冒充独立事件预测。
该“有效 AOD”可能吸收未建模的光源、廓线或云效应，不应直接当作真实气溶胶测量值。

校准后 503 nm 内侧仍偏亮，677 nm 最外侧则偏暗约 19%。**剩余误差的空间和光谱结构仍被保留**，
没有再增加高度、谱指数或显示参数把它们压平。滤镜响应和观测误差缺失，无法给偏差赋予严格显著性。
曲线读数有平滑相关性，RMS 只是描述量，不是独立样本统计量。

## 验证、产物与复现

[观测对照图](../figures/round2/comparison.png)、[分析 JSON](../validation/results/round2/analysis.json)
和 CSV 保存全部读数、参数、代码哈希、候选探针、校准划分与贡献高度。
新默认图像在 [figures/round2/render](../figures/round2/render)，历史快照保持原样。

独立验证包括直线指数层的精确 Bessel 光深、分段笛卡尔曲线光路 ODE、带气溶胶的全平面能量预算，
以及零 AOD、550 nm 锚点和分子几何不变检查。本轮独立光深比较约达 1e-9 相对量级，
全平面能量闭合约 1.3e-9。默认光谱网格 5→2.5 nm 的明视觉亮度差约 0.41%，
路径表 100→50 米约 0.11%；这些是声明模型的数值检查，不是大气廓线正确性的证明。
