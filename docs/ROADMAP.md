# 从粗到精的项目路线

## 目标与当前边界

目标是从太阳光谱和地球大气中的传播行为，计算月球位置处的光谱照度，再模拟月食月面的颜色，
包括本影外缘的冷色带。每轮先用观测或独立计算定位一个主要缺口，再增加一项物理内容，
比较相同条件下的光谱、亮度和空间分布；不以调出想要的颜色作为改进依据。

当前主输出仍是月球距离处、垂直日地轴的平面上的光谱照度。月球图片是中性月面屏的示意，
尚未包含真实月壤和观察者。现有 2011 年两波段观测曲线没有覆盖绿松石带本身，
不能据此宣称已经验证完整可见颜色、色带宽度或饱和度。

[MODEL.md](MODEL.md)负责物理与数值契约；[OBSERVATIONAL_VALIDATION.md](OBSERVATIONAL_VALIDATION.md)
负责观测口径和首轮对照；本文件记录已经走到哪里，以及后续方向的进入条件。

## 本轮的选择

本轮只把**气溶胶造成的额外消光**加入传播模型。当前残差的高度分布指向较低掠过路径的缺失消光；
太阳临边昏暗的诊断没有消除深本影红光偏亮，因而本轮优先处理自由对流层气溶胶。
这是一项有证据支持的选择，不构成对气溶胶的唯一因果识别。

默认廓线及光谱规律来自独立文献中的背景模型，见
[physics/AEROSOL.md](physics/AEROSOL.md)。默认比较不拟合亮度比例或空间偏移，
不同时加入边界层、平流层气溶胶或云。若以 677 nm 标定单一 AOD，必须单列为诊断：
保持独立先验的比较，用 503 nm 作波段留出检查，并说明同一次月食的留出波段仍不是新事件的独立验证。

这轮之后的残差应继续保留。通过增加参数贴合一组曲线，不能替代公开观测误差、仪器响应和独立事件。

## 后续方向与进入条件

以下是按证据组织的候选方向，不是承诺一次实现全部内容。每轮从当前残差中选择一个能够判别的方向。

| 方向 | 要解决的缺口与进入条件 | 有用的观测量或检查 |
|---|---|---|
| 补齐滤镜与观测口径 | 当残差已经接近未知带宽、站点或月面几何的影响时，优先获取响应曲线、时刻、指向及误差；不能继续把单色预测当作严格带通预测 | 同月面单元的食中/食外带通比；按响应积分后的光谱；几何条件敏感性 |
| 增加独立月食事件 | 检验固定廓线是否只碰巧适合 2011 年西侧曲线；任何标定结果都需要新的观测事件检验 | 未参与标定的事件、位置和波段，保留绝对归一化 |
| 提取公开 HST 光谱 | 公开归档已确认可用；需先恢复实际月面采样位置并处理指向漂移、月面反照率和发表结果的修正口径 | 蓝端光谱斜率和食中/食外谱比。其波段不能独自验证完整约 600 nm 吸收谷 |
| 实际温度与臭氧高度廓线 | 气体密度梯度同时影响折射和消光；相同臭氧柱量可以有不同高度分布。出现位置偏移或臭氧吸收形状残差时检查 | 光路最低高度、偏折、吸收谷及径向谱比；每次只改变一个廓线条件 |
| 太阳临边昏暗 | 当前采用均匀太阳。它在本次诊断中没有解决主要深红偏亮，但仍会改变不同太阳区域的光路权重，不能视为永远可忽略 | 统一总太阳通量后的空间与光谱变化；无地球遮挡极限及接近本影边缘的对照 |
| 有观测约束的气溶胶廓线 | 当前只含一个背景自由对流层组件；若残差随高度或事件变化，应检查独立气溶胶资料，而非不断放宽同一曲线的拟合自由度 | 廓线消光、垂直 AOD 与斜路径透过率；固定先验、校准及独立预测分别报告 |
| 波长相关折射 | 当前所有波长沿参考路径。若色带位置或窄空间结构成为误差重点，再量化色散 | 不同波长的光路及落点、色带位置和宽度；逐波长的守恒与光线核验 |
| 一次散射进入接收方向 | 当前只计算未散射光及散射出射束的损失；在短波、透射很弱的位置或特殊气溶胶条件下，散入光可能重要 | 将直接与散射项分开保存；有仪器响应的光谱、角分布和独立参考计算 |
| 多次散射 | 只有一次散射结果、观测或光学厚度证据表明其不足时进入，避免过早承担高计算成本 | 分阶贡献与收敛、独立辐射传输参考、跨事件光谱；不能只凭图像更亮判断正确 |
| 三维大气、云和地球边缘天气 | 球对称模型无法解释明显的东/西不对称及局部暗区；需要沿地球边缘有位置和时刻的大气资料 | 二维月面光场、方向差异和时间变化。云与气溶胶应有各自的约束，避免相互代偿 |
| 真实月面反射和观察者 | 当前月面屏省略月壤光谱、BRDF、球面入射角与观测站大气；在匹配月球照片或地面绝对测光前补齐 | 真实月面区域的反射光谱与辐亮度；大气外/地面观测区别，保留照明场作为独立输出 |
| 视觉与显示 | 明视觉 CIE 色度学加共同曝光不足以预测暗适应体验；只有讨论肉眼外观或相机成像时再引入相应模型 | 原始光谱和光度量、共同曝光图、色度诊断分别保留；标注相机响应、色适应及明/中间/暗视觉条件 |

## 绿松石带需要的证据

验证该现象需要覆盖相关可见光波段、接近本影边缘，并记录位置和仪器响应的观测。
目前的两个波段和偏内部曲线只约束部分传输行为。后续应分别比较：

- 光谱上臭氧吸收及其他消光造成的形状变化；
- 空间上冷色区域的位置、宽度及其与亮度梯度的关系；
- 在明确曝光与显示规则下的可见程度。

图像颜色相似本身不能关闭这些问题。改变曝光、白点、月面反射或观察条件时，应能回溯到相同的物理光谱。

## 每轮的推进判据

先保存当前模型、参数和参照条件，再提出能解释残差分布的候选原因；用低成本的真实计算区分候选，
选一个实施。改动后同时检查数值正确性、对既有观测的影响及明确未解决的残差。
新增项若没有带来目标可感知的收益或可验证的物理改进，就重新审查其方向和存续理由。
未解决的物理缺口、尚未闭合的观测口径与单纯的显示选择应分别记录，避免用一类问题补偿另一类。
