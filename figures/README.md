# Figure gallery index

One section per subdirectory; each directory self-documents via its own
README/metadata where present. Cross-generation caution: `mainline/` is the
current production lane, while the other directories are historical snapshots
of earlier model generations — their fixed OPAC is the v0.2 free-troposphere
single layer, not the current two-layer default. Historical figures must not
be mixed with current ones as same-state validation; see
[MAINLINE](../docs/MAINLINE.zh.md) on generational labeling.

## mainline — current production lane

`mainline/` holds the three-state disk figures, the transmission ladder and
the shadow profile of the current production CLI, with a single-source
`metadata.json` provenance ledger (per-state commands, input fingerprints,
per-figure SHA256). Reading conventions and generational boundaries:
[mainline/README.md](mainline/README.md). Deterministic offline re-render:
`uv run python tools/render_mainline.py --out <new-dir>`.

## baseline — first molecular model

`baseline/` contains the report figures and metadata produced by:

```bash
uv sync
uv run lunar-eclipse simulate --aerosol none --out outputs/baseline
```

The committed PNGs and `report.json` are copied unchanged from that output.
All numerical arrays can be regenerated into ignored `outputs/baseline/`.

Conditions: spherical standard dry atmosphere, Gaussian 300 DU ozone profile,
uniform finite solar disk, mean Earth–Sun and Earth–Moon distances; 550 nm
achromatic refracted paths with wavelength-dependent molecular and ozone
extinction. No aerosol/cloud attenuation or light scattered into the receiver.

`ozone_comparison.png` changes absorption only, under the same exposure and
solar-white adaptation. The cold gray-blue outer edge is present with ozone
and absent without it. A distinct observed turquoise band has not yet been
established. `moon_chromaticity.png` removes brightness and must not be read
as a photometric image. All disk images are neutral shadow-plane screens.

The default offset 2860 km puts the entire lunar screen just inside the
geometrical umbra (radius approximately 4599.7 km), with its outer edge at
4597.4 km. `moon_exposures.png` shows the substantial effect of global exposure.

## observations2011 — first-round comparison

`observations2011/comparison.png` is generated by:

```bash
uv run python -m validation.compare_observations --out outputs/observations2011
```

It compares the unchanged first model with digitized published observed curves,
not another model's prediction. See [the comparison contract](../docs/records/OBSERVATIONAL_VALIDATION.md)
for missing bandpasses, unknown observational uncertainties and interpretation.

## round2 — aerosol extinction round

`round2/comparison.png` compares the molecular baseline, the independent fixed
OPAC prior and a separately labeled red-band AOD calibration. The latter is
never the default; blue observations are withheld from its fit. Generate with
`uv run python -m validation.round2_analysis --out outputs/round2`.

`round2/render/` contains the round2-era default OPAC-prior visualization,
produced by `uv run lunar-eclipse simulate --out outputs/current`. Metadata
accompanies the figures. Original baseline/observations2011 snapshots above
are unchanged. See [ROUND2.md](../docs/records/ROUND2.md) and
[ROADMAP.zh.md](../docs/ROADMAP.zh.md).

## stratosphere_background — two-layer default render

`stratosphere_background/render/` contains the current-default visualization,
produced by `uv run lunar-eclipse simulate --out outputs/strat-render`. The
default is now the two-layer OPAC column (free troposphere 2–12 km plus
stratospheric background 12–35 km), so the disk is slightly darker than the
round2 render (axis relative photopic irradiance 3.78e-5 versus 4.28e-5, about
0.18 stops). The `round2/render/` snapshot above stays frozen as the
round2-era default. See [physics/AEROSOL.md](../docs/physics/AEROSOL.md) and
the `preregistered_check` under [validation results](../validation/results/stratosphere_background/).

## multiple_events — 1990 / 2007 photopic comparison

`multiple_events/comparison.png` compares published whole-disk photopic
brightness (1990) and the 2007 extrapolated minimum (explicitly context only)
against historical single-layer fixed models. Generated by
`uv run python -m validation.multiple_events --out outputs/multiple-events`.
See [MULTI_EVENT_OBSERVATIONS.md](../docs/records/MULTI_EVENT_OBSERVATIONS.md).

## dec2011 — December 2011 exposure-averaged spectra

`dec2011/comparison.png` compares the December 2011 full-exposure-averaged
spectra (nominal Tycho site, independent ephemeris, position sensitivity)
against historical single-layer models. Generated by
`uv run python -m validation.compare_dec2011 --out outputs/dec2011`.
See [DECEMBER2011.md](../docs/records/DECEMBER2011.md).

## filter_response_2011 — assumed-bandpass probe

`filter_response_2011/comparison.png` probes the June single-band comparison
under an assumed bandpass envelope (not a measured response). Generated by
`uv run python -m validation.filter_response_2011 --out outputs/filter-response`.
See [OBSERVATIONAL_VALIDATION.md](../docs/records/OBSERVATIONAL_VALIDATION.md),
filter-protocol section.
