# 2019-01-21：HST/STIS 星载口径的独立事件光谱

来源是 [Youngblood et al. (2020), arXiv:2008.01837](https://arxiv.org/pdf/2008.01837v1)（HST-GO/DD-15674），
这是第一个星载（HST，低地球轨道）接收者的独立月食对照，无地面气团量，但引入指向漂移这一新误差源。

## 数据合同

`source.json` 记录全部下载产品（SHA256 + 字节数 + FITS 头观测记录）与检索事实。
MAST 元数据 API（v0.1/v0.3 invoke）在检索时不可用（HTTP 404），溯源锚定到产品字节 SHA256；
含十六进制后缀的数据集产品名在 MAST 全小写服务（如 `ody9040a0_flt.fits`）。
原始 FITS 缓存于忽略的 `outputs/sources/hst2019/`，仓库只保留本合同与派生小文件。

G430L（2889–5696 Å，52X2 狭缝）分组：

- **本影（食中）**：`ody902030`（3×154.7 s CR-SPLIT）与 `ody902040`（2×154.8 s），主比值进比较；
- **半影（辅助）**：`ody9a2010`（3×48.3 s）与 `ody9a2020`（3×20 s），只作辅助检查，不进主比值；
- **全月（食外参考）**：`ody904080`–`ody9040j0` 共 12 次单次曝光（5×0.5 s + 7×0.7 s）。

`table1_exposures.csv` 转录论文 Table 1 的 G430L 行（mid-time、eclipse angle、线性轨道月面经纬度）。
CR-SPLIT 成员归属按论文 Table 1；机械核对：管线 `_crj` 曝光时间和 ≈ 成员之和。

## 提取与文献口径

管线 `_sx1/_x1d` 的通量列使用点源提取（背景区放在被狭缝充满的月面光谱上），对本数据语义错误，
**只取其波长解，绝不取其通量**。2D 提取复现论文自己的方法（CalSTIS `_flt` → L.A.Cosmic → x2d →
跨色散方向中位数合并）：本管线在 `_crj`（管线 CR 拒绝组合）或单次 `_flt` 上按列做全缝（52″）
无背景中位数合并，再除以曝光时间。论文对每次曝光除以 Lommel-Seeliger 因子（范围 0.4975–0.5021，
入射/发射角强耦合），本管线省略该 ≤1% 的比值效应并记录在案；论文只对半影谱除以临边昏暗因子
（G430L I/I₀ ≈ 0.7–0.79），本影谱无此项——因此本影主比值与论文口径直接对齐，半影辅助比值
与发表值存在已知约 1/0.75 的系统性差异。无绝对流量定标（比值内仪器响应抵消），与论文一致。

## 指向与几何

论文用陀螺导星 + 3–4 段线性轨道近似月面非线性视运动，指向不确定度 = 初始陀螺转动 ~14″ +
陀螺导星累积（~0.001″/s）+ 线性轨道近似误差（主导，最大 ~10′）。
`geometry.json` 保存：逐 exposure 采样点（Table 1 月面经纬度，IAU 东经为正——经 FITS `RA_APER/DEC_APER`
独立核对裁决）在反射历元的影轴距离（Horizons DE441 + MEAN_ME 高精度月球定向，站点矢量与
Dec 2011 同机制）、eclipse angle 对 Table 1 的独立核对、±150 km 采样位移与论文指向包络两级敏感性。
论文自评指向漂移使 in/out 采样区域不同、月面反照率不能完全抵消——这是本对照的前提边界，不修补。

## 复现

```sh
uv run python tools/fetch_hst2019_geometry.py   # 联网重建几何（Horizons，缓存同目录）
uv run python -m validation.compare_hst2019 --out outputs/hst2019
```
